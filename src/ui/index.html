What C0 Infers from Sample XMLs

  • 1. Element & Attribute Inventory

    Unions all XPaths across every sample file. Elements present in <100% of samples are marked required: false.

  • 2. Narrowest Snowflake Type Ladder

    Tests NUMBER(18,0) → NUMBER(18,4) → DATE → TIMESTAMP_NTZ → BOOLEAN → VARCHAR across all values.

  • 3. Array & LATERAL FLATTEN Detection

    Repeating nodes under the same parent set is_array: true and generate LATERAL FLATTEN in DDL.

  • 4. Confidence Scoring for C3 Review

    Fields below threshold (e.g. 0.50) are highlighted for the Data Steward at Stage ③.
