End-to-End 3-Step Agentic Workflow

  • Step 1: Data Steward Agent (Claude Haiku)

    Reads XML schema & creates raw_schema.yaml (Normal Table — not DDL). Models Stage & Final Gold layers as Dynamic Tables (staging_schema.yaml, gold_schema.yaml, data_model.yaml) and pauses for human approval.

  • Human Gate (C3): Approve YAMLs & Model

    Review and edit the 3-layer YAML schemas, Claude's semantic descriptions, PII tags, and dimensional Gold model before any SQL is generated.

  • Step 2: DDL Generator Agent

    Once approved, compiles SQLs for all 3 layers: ADLS → RAW (Snowpipe), RAW → Stage (Dynamic Table), Stage → Final Gold (Dynamic Table) + deployment manifest.

  • Step 3: E2E Deployment & Final Sign-Off

    Deploys all generated SQLs end-to-end (ADLS to Gold), runs Catalog/DQ/Monitoring/Smoke Test, and presents the Final Sign-Off screen.
